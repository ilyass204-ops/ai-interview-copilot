# AI Interview Practice Copilot

A real-time AI assistant that listens to interview questions, searches my own
background (CV, projects, courses) and suggests answers on screen or by voice.
Includes a practice mode that scores my answers.

## Status
🚧 Phase 0: project setup

## Planned stack
Python · faster-whisper (local speech-to-text, GPU) · RAG with ChromaDB · LLM API · PyQt overlay
